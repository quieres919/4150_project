# Hist1 Genomic Analysis
 
## Overview
This project analyzes Genome Architecture Mapping (GAM) data from the Hist1 region on chromosome 13.
 
## Techniques
- K-Medoids Clustering
- Jaccard Distance Analysis
- Feature Enrichment Analysis
- Network Analysis
- Data Visualization
 
## Technologies
Python, NumPy, Pandas, Seaborn, Matplotlib, NetworkX
 
## Results
- Identified three biologically distinct NP clusters
- Generated similarity heatmaps
- Performed chromatin interaction network analysis
- Measured enrichment of Hist1, LAD, RNAPII, and transcription factor features
